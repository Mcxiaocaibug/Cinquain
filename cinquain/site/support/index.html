SERVER SUPPORT

连接与支持

如果客户端无法登录，请先确认 homeserver 地址与账户域完全一致。

客户端设置

在 Element 或其他 Matrix 客户端中选择“编辑 homeserver”，输入当前网站的完整 HTTPS 地址。

账户管理

使用服务器内置的安全账户页管理登录、密码和设备。

打开账户页 →

运营者诊断

服务器运营者可在部署目录执行 ./cinquain doctor，检查 TLS、联邦、discovery 与客户端 API。

隐私提示

端到端加密房间的消息内容仅参与者设备可解密。服务器仍会处理必要的账户与联邦元数据。
